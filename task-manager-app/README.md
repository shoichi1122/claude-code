# 🗓 マイタスク(自分専用タスク管理)

「深夜0時のMTGを翌日の予定だと思って寝てしまう」「出発が遅れて遅刻しそう」を防ぐための、スマホ向けタスク管理Webアプリです。

公開版(main にマージ後): **https://shoichi1122.github.io/claude-code/task-manager-app/**

スマホで開いて **「ホーム画面に追加」** するとアプリのように使えます(iPhoneはこれをしないと通知が届きません)。

## できること

### 🌙 日付をまたぐ予定を「その日の夜」として表示
- 1日の区切りを **5:00**(設定で0:00〜8:00に変更可)にしているので、11/9 0:00 のMTGは **「11/8 の 24:00」** として11/8の画面に並びます
- 時刻は数字だけで入力OK: `2400` → 24:00、`2530` → 25:30、`0:30` → その日の24:30
- 日付が変わる位置に「🌙 ここから日付が変わります — でも今日の夜の予定です」の区切り線
- 今夜に深夜の予定があると、画面上部に紫のバナー+指定時刻(初期値21:00)に「今夜、深夜の予定があります」アラーム
- Googleカレンダーから取り込んだ予定も、0:00〜5:00 のものは自動で前日の夜に振り分け

### 🚗 目的地に10分前に着く出発アラーム+ナビ
- 予定に「目的地・移動手段・所要時間」を入れると、**開始10分前に到着する出発時刻**を逆算(何分前に着くかは予定ごと・設定で変更可)
- 出発の15分前に「準備開始」、出発時刻に「出発の時間です!」のアラーム(音+バイブ+通知)
- 「🧭 ナビ」で Google マップ(または Apple マップ)のナビをそのまま開始
- 電車の場合は Yahoo!乗換案内を **到着時刻指定(10分前着)** で検索
- 「📅 アラーム登録」で、出発アラーム付きの予定を .ics で書き出してスマホのカレンダーに登録(アプリを閉じていても端末のカレンダーが鳴らしてくれます)

### 🛣 渋滞を考慮
- **APIキーなし**: 時間帯ルールで渋滞分を上乗せ
  - 平日朝・夕ラッシュ +30%、五十日(5・10日)の午前 +10%
  - 休日の高速道路: 朝の下り +40%、夕方の上り +50%
  - GW・お盆・年末年始の高速 +60%、雨・雪 +15%
  - 何をいくつ上乗せしたかは各予定に表示されます
- **Google Maps APIキーあり(任意)**: Routes API の交通予測で、到着したい時刻から逆算した出発時刻の所要時間を取得。さらに出発90分前〜開始までは **現在地から5分ごとに到着予測を更新** します

### ✉️ 遅刻しそうなら連絡文を自動作成
- 出発時刻を過ぎても「出発した」を押していない/現在地からの到着予測が開始時刻を超えた場合に、**「約◯分遅刻しそうです」アラーム**を出します
- 連絡文を自動で作成(遅れる分数は5分単位で切り上げ、到着予定時刻入り)
  - 文体: ビジネス(丁寧)/カジュアル/短文(SMS向け)
  - 理由: 渋滞・高速の渋滞・電車遅延・前の予定・出発遅れ・体調不良・書かない(自動判定は実際の状況に合わせ、渋滞が検知できないときは「出発が遅れた」になります)
  - オンラインMTG(移動なし・URL)の場合は「先に始めていただければ」の文面に
- コピー/共有/LINE/メール/SMS ボタンで、宛先と本文を入れた状態で各アプリを開きます(最終送信は自分で確認してから)

### その他
- 「やること」: 時間の決まっていないタスク。未完了は翌日に持ち越し
- 「🔔 待機」: 画面をつけたままにしてアラームを確実に鳴らすモード(就寝前に深夜予定があるとき、充電しながら使うのがおすすめ)
- 左右スワイプで日付移動、ダークモード対応、オフラインでも起動
- バックアップ(JSON)の書き出し/復元

## アラームについての注意
ブラウザの仕様上、**アプリを完全に閉じている間はアプリ自身のアラームは鳴りません**。確実に鳴らすには次のどれかを使ってください。
1. 「📅 アラーム登録」で端末のカレンダーに出発アラームを登録する(いちばん確実)
2. 「🔔 待機」モードで画面をつけたままにしておく
3. 開いたまま(バックグラウンド)にしておく — 端末によっては止められることがあります

## 渋滞のリアルタイム予測(任意)のセットアップ
1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成し、**Routes API** を有効化(請求先アカウントの設定が必要。個人利用なら通常は無料枠内)
2. 「認証情報」→「APIキーを作成」
3. キーの制限: 「ウェブサイト」で `https://shoichi1122.github.io/*` を許可、API は Routes API のみに制限
4. アプリの ⚙ 設定 →「Google Maps APIキー」に貼り付け
- キーはこの端末のブラウザ(localStorage)にだけ保存され、バックアップファイルにも含めません

## Googleカレンダー取り込み(任意)
「今日の予定まとめ」アプリと同じ OAuth クライアントIDを使えます(同じサイト上なら設定済みのIDがそのまま読み込まれます)。作り方は [daily-schedule-app/README.md](../daily-schedule-app/README.md#googleカレンダー連携のセットアップ初回のみ) を参照してください。権限は読み取り専用です。

## 技術構成
- 単一の `index.html`(HTML / CSS / Vanilla JS)+ PWA用の `manifest.webmanifest`・`sw.js`
- データはすべてブラウザの localStorage に保存(外部サーバーには送りません)
- 外部通信は、任意設定した場合の Google Routes API / Google カレンダー API のみ

ローカルで動かす場合:
```bash
cd task-manager-app
python3 -m http.server 8000   # → http://localhost:8000
```
