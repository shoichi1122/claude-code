# 💐 お礼文メーカー

イベント後のお礼メッセージを、相手の種類ごとのテンプレートから作って、Instagram DM / LINE で送るためのWebアプリです。

BTN(BREAK THE NORMS)は「ダンサーファースト」をモットーにしたイベントなので、出演ダンサー向けのお礼文を中心に、関わってくれたすべての人へのお礼をまとめて管理できるようにしています。

## 使い方

公開版: **https://shoichi1122.github.io/claude-code/thank-you-app/** — 開くだけで使えます。

ローカルで使う場合は `index.html` をブラウザで開くだけで動きます(データはブラウザのlocalStorageに保存されます)。

1. 「🎪 イベント」タブでイベント名・開催日・場所を登録
2. 「📝 テンプレ」タブで差出人(例: `BREAK THE NORMS 主催 SHOICHI`)を設定
3. 「💌 送る」タブで、相手の種類・送り方を選び、名前を1行に1人ずつ貼り付けて追加
4. 各相手の「💌 お礼文を作る」→ ひとことを入れて文面を確認 → コピー / アプリを開いて送信

## 機能

### 💌 送る
- 相手の名前をまとめて貼り付けて一括追加(イベント・相手の種類・送り方・ひとことは共通で設定)
- 「お礼文を作る」で、テンプレに名前・イベント情報・ひとことを差し込んだ文面をプレビュー
  - テンプレの切り替え、その人だけの「ひとこと」入力、文面の直接編集ができます
- **LINE**: 「LINEを開いて送る」で本文入りのLINE共有画面が開くので、送る相手のトークを選ぶだけ
- **Instagram**: 名前を `@アカウント名` で登録しておくと、「コピーしてInstagramのDMを開く」でその人のDM画面が直接開きます(貼り付けて送信)
- コピー / アプリを開くと自動で「送信済み」になり、未送信・送信済みの人数とイベントごとの進み具合が分かります

### 📝 テンプレ
- **相手の種類**(出演ダンサー・来場者・スタッフ・協力者・スポンサー・スピーカー+自由に追加可)× **送り方**(Instagram DM / LINE)で管理
- 初回起動時に 5種類 × 2送り方 = 10件のサンプル文面入り(自由に編集・削除可)
- 差し込みタグ: `{名前}` `{イベント名}` `{日付}` `{場所}` `{ひとこと}` `{差出人}`
  - `{ひとこと}` が空の相手では、その行ごと自動で消えます

> **なぜ「コピー」中心なのか**: Instagram DMやLINEは、公式の仕組みでは個人アカウントから相手へ自動送信できません(規約違反・凍結リスクがあるため)。そのため送信の最終ステップは手動とし、送信画面をワンタップで開けるようにしています。

### 🤖 ノートからAIで下書き
- 「お礼文を作る」画面の「ノートからAIで感想の下書きを作る」で、話を聞きながら取ったノート(手書きのPDF・写真もOK)と自分のメモから、感想部分(学び・これからやること)の下書きをAI(Claude)が作ります
- 宛名と締めの挨拶はテンプレ側で付くので、AIは真ん中の感想だけを書きます
- 「テンプレ」タブの「お手本の文章」に過去のお礼文を貼っておくと、その書き方を真似します。送信済みにした同じ種類の相手の感想も、自動でお手本になります
- 使うには「テンプレ」タブで Claude のAPIキーを設定します([Claude Console](https://console.anthropic.com/settings/keys) で発行。利用した分の料金がかかります)
  - キーはその端末のブラウザにだけ保存され、バックアップ(JSON)には含まれません。共用の端末では設定しないでください
- 下書きはあくまで下書きです。送る前に自分の言葉に直してください

### バックアップ
- 画面下の「バックアップ(JSON)」「復元」で、データの保存・別端末への移行ができます
